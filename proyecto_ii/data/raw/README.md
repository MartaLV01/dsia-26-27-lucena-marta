# Datos originales

Esta carpeta está destinada a almacenar los archivos CSV originales del dataset **Goodbooks-10k**, creado por Zygmunt Zając.

Fuente: https://github.com/zygmuntz/goodbooks-10k

Para ejecutar el proyecto es necesario descargar los siguientes archivos:

- `books.csv`: información y metadatos de los libros.
- `ratings.csv`: valoraciones realizadas por los usuarios.
- `book_tags.csv`: relación entre libros y etiquetas.
- `tags.csv`: información de las etiquetas disponibles.
- `to_read.csv`: libros que los usuarios han añadido a su lista de lectura.

Los archivos deben conservarse en su formato original, sin modificaciones manuales.

**Importante:** los CSV originales completos no se incluyen en el repositorio. Cada usuario debe descargarlos desde la fuente indicada y colocarlos en esta carpeta.
